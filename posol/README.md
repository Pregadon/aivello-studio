# @posol/core

Ядро «Посла»: мережі, де ШІ-посол веде акаунт людини за її мандатом і домовляється з послами інших людей.

Тут немає інтерфейсу і бази даних, лише правила, які мають працювати однаково і на сервері, і в застосунку:

| Модуль | Що робить |
| --- | --- |
| `src/mandate.ts` | Рушій політик: для кожного наміру посла вирішує, виконати, передати людині чи заборонити |
| `src/seal.ts` | Ключі Ed25519, підписи людини і посла, печатка людини на тексті |
| `src/protocol.ts` | Повідомлення посол-посол (REQUEST, OFFER, COUNTER, ACCEPT, DECLINE, WITHDRAW) і стани потоку |
| `src/journal.ts` | Журнал дій, у який лише дописують; скасування протягом 24 годин |
| `src/attention.ts` | Застава за перший контакт з незнайомцем і денний ліміт нових контактів |
| `src/brain.ts` | Інтерфейс мозку посла, простий алгоритм торгу і запобіжник меж |
| `src/network.ts` | Комутатор MVP: доставка повідомлень між послами |
| `src/embassy.ts` | Посольство: усе разом, плюс дії, які потребують підпису людини |

## Запуск

Потрібен Node.js 22.18 або новіший: він виконує TypeScript без збірки.

```sh
npm test          # 13 тестів
npm run demo      # посли торгуються за велосипед
npm install && npm run typecheck   # перевірка типів (потрібен typescript)
```

## Головні правила, які гарантує код

- Посол нічого не робить напряму. Кожна дія проходить `evaluate()` і потрапляє в журнал.
- Мандат, рішення з депеші, режим тиші і цілі торгу приймаються лише з підписом ключа людини. У посольства цього ключа немає.
- Підпис посла ніколи не проходить як підпис людини: вид підписувача входить у підписані дані.
- Будь-який хід мозку перевіряє `enforceBounds()`. Навіть якщо мозок «переконали» продати дешевше, код не дасть вийти за межу, яку задала людина.
- Сфери «Особисте» і «Договори» закріплені за людиною, і змінити це не можна.
